Key Finding:

            
For Mimir's CURRENT use cases (structural queries, path finding):
✓ Static methods (current) = Perfect
✗ Neural networks = Overkill

Neural networks ONLY add value for:
• Personalized pattern learning (you + Mimir evolving together)
• Cross-codebase transfer learning  
• Reducing LLM API costs (Phase 1 - we're doing this!)

    # ... LLM call costing $0.0015 ...

def _classify_query(self, query: str) -> str:

    return classify_query(query)  # < 1ms, $0.000001
